# MangaVoice downloads

MangaVoice is a free, native Windows manga reader built first for blind and
visually impaired readers who use NVDA. It reads the text on manga pages
aloud and describes pages using a vision model running on your own computer.

## Download

Get the latest version from the
[Releases page](https://github.com/swarup-developer/mangavoice-releases/releases/latest):

- **MangaVoice-Setup-x.y.z.exe**: run it and choose Install. It installs for
  your Windows account only (no administrator rights needed), adds a Start
  menu shortcut, and updates itself. Remove it in Windows Settings, Apps.
- **MangaVoice-Portable-x.y.z.exe**: runs without installing and keeps its
  data in a `MangaVoiceData` folder beside it.

Requires Windows 10 or 11, 64-bit. The programs are not code-signed yet, so
Windows SmartScreen may warn the first time: choose More info, then Run
anyway. Each file has a `.sha256` checksum beside it.

## Help

Press F1 in MangaVoice for the full guide and every keyboard shortcut.
Report problems in [Issues](https://github.com/swarup-developer/mangavoice-releases/issues).
